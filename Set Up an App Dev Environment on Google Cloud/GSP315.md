<h3> Setup Environment using Cloud Shell:</h3>

```bash

curl -LO raw.githubusercontent.com/anushri-sharma/Google-Cloud-Computing-Foundation/main/Set%20Up%20an%20App%20Dev%20Environment%20on%20Google%20Cloud/GSP315.sh

# Give Execute Permission
sudo chmod +x GSP315.sh

# Run the Script
./GSP315.sh
```
